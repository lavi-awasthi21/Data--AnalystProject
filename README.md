# Super Store Sales Analysis – Power BI

## 📊 Project Overview
<img width="1372" height="790" alt="image" src="https://github.com/user-attachments/assets/f62ec3f6-e548-4a67-a065-8beadb5908dd" />

This project is an interactive Sales Analytics Dashboard created using Microsoft Power BI.

The dashboard is designed to analyze sales, profit, quantity, delivery performance, product categories, customer segments, payment modes, shipping modes, and regional performance.

It also includes a sales forecasting visualization to understand possible future sales trends.

---

## 🎯 Objectives

The main objectives of this project are:

- Analyze total sales and profit
- Track total quantity sold
- Analyze average delivery time
- Compare sales and profit across different categories
- Analyze sales by customer segment
- Analyze sales by payment mode
- Analyze sales by shipping mode
- Analyze monthly and yearly sales trends
- Compare regional performance
- Analyze sales and profit by sub-category
- Understand future sales trends using forecasting

### Profit Analysis

- Profit by Sub-Category
- Profit by Segment

### Operational Analysis
- Average Delivery Time
- Sales by Ship Mode

### Forecasting
A forecasting visualization was used to analyze the sales trend over time and estimate possible future sales based on historical patterns.
